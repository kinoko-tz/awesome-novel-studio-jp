# カクヨム向けプリセット — 厳選大ヒット路線（DRAFT）

このプリセットは、カクヨムを投稿プラットフォームとする作品に対し、
ターゲット読者・作品スタイル・カタルシス構造・伏線方針・感情曲線・ハッピーエンド規約を
一括で上書き定義する。`novel-config.md` の生成・各スキルの設計判断・推敲軸の重み付けに参照される。

> **位置づけ**: 既存のマルチプラットフォーム対応は維持したまま、カクヨムを選択した場合に
> 適用される「選択式プリセット」として追加する。他プラットフォームの挙動は変更しない。

---

## 1. 背景・狙い

KADOKAWA の決算で、なろうテンプレ準拠の「小ヒット」を連発した結果、利益率が低下した。
今後は **大きく売れる作品を厳選・発掘する** 方針に転換する見込み。
このプリセットは、その方針に沿って「量産型の小ヒット」ではなく「厳選された大ヒット候補」を
カクヨム上で狙うための作風ガイドである。

カクヨムは無料公開 + 書籍化スカウト / 各種コンテスト型のプラットフォームであり、
PV ランキング上位を取る戦略と、編集者・コンテスト審査員に評価される戦略は **別ゲーム** である。
本プリセットは後者（書籍化・コンテスト評価）に最適化する。

---

## 2. ターゲット読者（再定義）

- **主軸**: 偏差値 60 以上の高校生・大学生
- **感性軸**: 編集者 / 将来編集者になりそうな層が好む感性
- **含意**:
  - 単なる消費型読者ではなく、**構造・伏線・考察を楽しむ層**
  - 「読みやすさ」だけでなく「読み返したくなる仕掛け」「議論の余地」を評価する
  - クリシェの安心感より、**伏線の精度と回収の鮮やかさ**にカタルシスを感じる

> 既存の「想定読者層」記述（年齢層が曖昧）を、この具体ペルソナで上書きする。

---

## 3. スタイル方針（コア7原則）

1. **短期カタルシス**: 一般読者の離脱を防ぐ即効性の快感を各話に残す
2. **大量の長期伏線**: 後半で回収される伏線を多層に配置。考察の余地を意図的に作る
3. **二段の絶望（50%地点）**: 各章の 50% と 物語全体の 50% に「全てを失う絶望」を配置
4. **苦しみの持続と悲劇**: 苦しみは長時間持続しうる。主人公を凄まじい悲劇が襲う
5. **ラスト 80% で最強化**: 主人公は絶望を耐え抜き、物語のラスト 80% 区間で最強に近い存在となり、最大カタルシスを生む
6. **感情のジェットコースター**: 登場人物の感情は激しく上下する
7. **ハッピーエンド遵守**: 各章・物語全体のハッピーエンドは **必ず** 守る（最重要・絶対ルール）

## 4. 設計上の緊張関係と解決方針【要レビュー】

新方針には構造的に衝突しうる点が3つある。各スキルへ展開する前に、以下の解釈で合意したい。

### 緊張1: 「各章ハッピーエンド」 vs 「苦しみが長時間持続」
- **問題**: 章末を毎回ハッピーにすると、絶望は1章内で回収され「長時間持続」しない。
- **解決方針**: 「章末の必須カタルシス」を **完全解決ではなく、部分的勝利・希望の灯の最低保証** と定義する。
  - 物語をまたぐ大きな絶望は持続させてよい。
  - ただし各章末には「主人公が次へ進む意志」「小さな勝利」「関係の前進」のいずれかを必ず残す。
  - 完全な大団円は物語ラストにのみ置く。
- **「章」の定義**: 25話単位の幕（アーク）を「章」とみなす。各話末はクリフハンガー優先（既存ルール維持）。

### 緊張2: 「ラスト80%で最強化」の区間がもたらす中だるみ
- **問題**: 50% でどん底、80% で最強化開始だと、**50〜80% の3割が忍従だけ** になり一般読者が離脱する。
- **解決方針**: 50〜80% を「再起の階段」と位置づけ、**小さな勝利（短期カタルシス）を階段状に刻む**。
  - どん底（50%）→ 反撃の足がかり → 部分的勝利の連鎖 → 80% で最強化が完成、というカーブにする。
  - 「忍従の谷」を一枚岩にしない。各話に最低1つの前進または伏線回収を置く。

### 緊張3: 「考察・伏線重視（編集者層）」 vs 「短期カタルシス（一般読者）」
- **問題**: 重厚な考察作はカクヨムの一般読者に離脱されやすい。狙う層と PV 層が一致しない。
- **解決方針**: **二層設計** を採る。
  - 表層（一般読者向け）: 強い冒頭フック・各話の短期カタルシス・モバイル可読性で離脱を防ぐ。
  - 深層（考察層向け）: 長期伏線・多層構造・再読価値を仕込む。表層だけ追っても楽しめるが、深層に気づくと評価が跳ねる。
  - KPI は PV ランキングではなく **書籍化スカウト / コンテスト評価** に置く。

## 5. カタルシス構造マップ（プリセット既定値）

物語全体（仮に 100% で正規化）:

| 区間 | 役割 | 配置 |
|------|------|------|
| 0〜5% | 強力な冒頭フック（一般読者掴み）+ 長期伏線の種まき開始 | OPENING 軸を最優先 |
| 5〜50% | 上昇と布石。短期カタルシスを刻みつつ伏線を多層に積む | HOOK 強度を維持 |
| **50%（中間点）** | **全てを失う絶望（物語最大のどん底）** | 最大筆力を集中 |
| 50〜80% | 再起の階段。小さな勝利を階段状に刻む（中だるみ防止） | 各話に前進 or 伏線回収を1つ以上 |
| 80〜100% | 最強化の完成・伏線回収ラッシュ・最大カタルシス・ハッピーエンド | 全伏線を回収して着地 |

各章（25話のアーク = 1章）:

| 区間 | 役割 |
|------|------|
| 章の0〜50% | 章テーマの導入と上昇 |
| **章の50%** | 章レベルの絶望（章のどん底） |
| 章の50〜末尾 | 章レベルの再起 |
| 章末 | 部分的勝利・希望の灯（必須カタルシスの最低保証） + 次章へのクリフハンガー |

## 6. 既存方針からの変更点（なろうテンプレ前提の見直し）

| 既存（なろうテンプレ前提） | カクヨムプリセット |
|------|------|
| 馴染み7 : 新しさ3 | **馴染み5 : 新しさ5**（考察層は新規性を評価）。冒頭フックのみ馴染み寄りで掴む |
| 企画案「定石→変奏→挑戦」の3案固定 | **「挑戦型」を主軸**に。定石は冒頭の掴みにのみ使う |
| 課金転換 ±3話に最大筆力集中 | カクヨムは課金転換が無い。**コンテスト締切 / 書籍化スカウトの試し読み終端**（例: 10〜15話、25話、50話）に筆力集中 |
| カタルシス周期の公式化（5〜10話ごと固定） | 周期は維持しつつ、**50% の大絶望と長期伏線回収**を上位構造として重ねる |

## 8. リスク・反例（緩和策つき）

- **リスク**: 「絶望の長時間持続」は、一般読者の離脱を招く諸刃の剣。
  → 緩和: 緊張2の「再起の階段」で短期カタルシスを必ず刻む。離脱率を推敲 HOOK 軸で監視。
- **反例**: 編集者ウケと読者ウケが乖離し、PV が伸びずスカウトもされない最悪ケース。
  → 緩和: KPI を最初からスカウト / コンテストに固定し、PV 不振を失敗と誤認しない。冒頭フックだけは一般読者向けに強く保つ。
- **リスク**: 大量の伏線を回収しきれず「未回収のまま考察だけ煽る」失敗。
  → 緩和: 80〜100% を「伏線回収ラッシュ」と定義し、design 段階で伏線→回収の対応表を必須化する。
