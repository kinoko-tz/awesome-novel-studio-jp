# エピソード創作原則 詳細

episode-creator エージェントが詳細な執筆ガイドを必要とするときに参照する文書。

## 1. 場面構成原則

### 場面の開始
- 時空間アンカーで始める: 時間（具体的な時刻または相対時間）+ 場所（具体的な位置）
- 感覚ディテールを1〜2個入れて雰囲気を設定する（視覚／聴覚／触覚／嗅覚のいずれかを選ぶ）
- 直前の場面との時間間隔が明確でなければならない

### 場面の展開
- 一つの場面では一つの中心となる葛藤／目標だけを扱う
- 場面内の緊張曲線: 導入(30%) → 展開(40%) → クライマックス/転換(30%)
- 情報伝達は対話または行動を通じて行う（語り手の説明で直接伝達するのは禁止）

### 場面の締めくくり
- 次の場面への転換動機を残す（人物の決意、新情報、時間制限）
- 最後の場面は必ず未解決の状態で終わる

### 場面数とリズム
- エピソードあたり2〜4場面が適切。5場面以上だと散漫になる
- 緊張場面と弛緩場面を交互に配置する（連続3場面の高緊張は禁止）
- 各場面の長さは均等である必要はない。クライマックス場面に分量を集中させる

## 2. 対話作成原則

### 対話のリズム
- 3文以上の連続した対話の後には、非言語的な行動や内面描写を挿入する
- 対話タグは「言った」系統の代わりに行動タグを優先する
  - 悪い例: 「彼が言った」
  - 良い例: 「書類を置きながら」
- 一つの会話シーンで同じ行動タグを2回以上使わない

### 情報伝達の対話
- 専門家もので情報を伝達するとき: 一度に3文以上の説明をしない
- 聞き手の反応（質問、疑問、感嘆）を挿入して読者の理解を助ける
- 専門用語を使うときは文脈で自然に意味を伝える（脚注式の説明は禁止）

### 葛藤の対話
- 対立する二人の人物の対話: 一方が3連続で優位に立たない
- 押し引きの構造: 攻撃 → 防御 → 反撃のパターン
- 感情のエスカレーション: 対話が進むにつれて感情の温度が徐々に上がる

### 沈黙と非言語
- 沈黙は、キャラクターシートの沈黙例外人物（父親など）を除いて非言語表現に置き換える
- 非言語表現: 視線（凝視／回避）、姿勢（もたれる／硬直）、習慣的な行動（指で叩くなど）
- 人物ごとの固有の非言語パレットをキャラクターシートで確認する

## 2.5. 自然な日本語文体ガイド

### 根本原則: 「語り手は透明であるべき」
- 語り手が読者に「これは重要だ」「これは悲しい」「これは驚きだ」とシグナルを送ってはならない
- 場面を見せ、読者が自分自身で感情を感じるようにしなければならない
- AIの根本的な問題: 感情を「解説」しようとする傾向。日本語のWeb小説は行動と台詞で感情を伝える

### AI文体の自己診断チェックリスト
（文章を書いた後、自分で確認する）
1. この文を削除しても場面が伝わるか？ → 削除する
2. 感情名詞（恐怖、驚愕、諦め、喜び）が主語になっているか？ → 身体反応に置き換える
3. 語り手が状況を「整理」しているか？ → 削除して行動／台詞に置き換える
4. 同じ意味を別の比喩で2回以上使っているか？ → より強い1文だけを残す
5. 「〜のだった」「〜というわけだった」「〜と言えた」 → 直接叙述に置き換える
6. 最後の文が「こうして〜した」「新たな〜が始まった」の類か？ → 台詞／行動に置き換える

### 語り手の介入禁止パターン（具体的）
| パターン | 理由 | 代替 |
|------|------|------|
| 「それは〜だった」 | 語り手が解釈を強要する | 場面で見せる |
| 「〜ということを知った／悟った」 | 感情の解説 | 行動の変化で認知を表現する |
| 「〜ではなく〜だった」 | 対比構文の乱用 | 1文で直接叙述する |
| 「まさにその瞬間／そのとき」 | メタ叙述のシグナル | 削除し、行動で時点を示す |
| 「〜するのは〜のためだった」 | 因果の解説 | 原因→結果を場面の順序で見せる |
| 感情名詞 + 「が押し寄せた／こみ上げた」 | 感情の解説 | 身体反応（震え、呼吸の変化など） |
| 「新たな〜が始まった」 | メタ叙述のエンディング | 台詞または行動で締める |

### 比喩密度の制限
- 1段落に比喩は1個以下
- 3段落連続の比喩は禁止
- 比喩は人物の職業／経験から生まれるべき（年金専門家が「等比級数的減少」と比喩するのは自然）

### エピソードタイトル原則
- 1〜2語。名詞または名詞句。
- 修飾語、助詞、連体節を除く。
- 例: 「枯渇」「名札」「初面談」「警告」

## 3. フック配置戦略

### オープニングフック（最初の1000字）
- 事件への直接投入: 読者が3行以内に「何が起こっているのか」を把握できなければならない
- 禁止: 朝の起床、回想、世界観の説明、前話の要約
- 効果的な技法:
  - 対話の途中から始める（すでに進行中の状況に読者を放り込む）
  - 危機状況への直入（時間制限、失敗直前、葛藤の爆発）
  - 意外な情報の公開（読者が知らなかったことを人物が知っている）

### 中盤フック（50%地点）
- 反転または新情報の公開で読者の期待を再設定する
- 「知っていたことが事実ではなかった」パターンが最も強力である
- 技法:
  - 新人物の登場と既存の構図の変化
  - 隠された条件／制約の露呈
  - 同盟の亀裂、または敵の意外な弱点

### エンディングフック（最後の500字）
5段階のクリフハンガー（状況に応じて選択する）:
1. 弱: 新たな計画の宣言（「次はこうする」）
2. 普通: 予想外の人物の登場
3. 強: 重要情報の部分公開（全体ではなく一部だけ）
4. 非常に強: 危機への直面（時間制限、裏切り、失敗）
5. 最強: 世界観／人物設定をひっくり返す情報の公開

## 4. 専門家ものの情報統合

### 専門知識の露出原則
- 読者は専門知識そのものではなく、その知識による**状況の逆転**に興味を感じる
- 知識露出のパターン: 危機 → 専門知識の適用 → 状況逆転 → 周囲の驚嘆
- 一つのエピソードでの専門知識の核心活用は1〜2回に制限する（過剰露出 = 講義型叙述）

### 数値を自然に挿入する
数値は対話や状況の中で自然に露出させる:
- 悪い例: 「その土地の面積は1万2千坪だった。」
- 良い例: 「『一万二千坪ですか？』 部長が書類を再び覗き込んだ。」
- 悪い例: 「投資金は3億円が必要だった。」
- 良い例: 「三億。」 伊勢谷恋が指を三本立ててみせた。「それ以上は引っ張れない。」

### 回帰者の未来知識
- 未来知識を活用するときは「なぜ知っているのか」についての偽装ロジックを必ず含める
- 直接「未来から来たから」と考える独白は読者の共感を壊す
- 代わりに: 関連資料を事前に準備していたかのように見せる仕掛け、直感に偽装する、分析力で包装する

## 5. 日本プラットフォーム最適化

以下の原則は、カクヨム, 小説家になろう, アルファポリス, ノベルアップ+, エブリスタ, ノベルピアに共通して適用する。
細かい基準はプロジェクトの `target_platform` に合わせた `_workspace/platform-guide-{プラットフォーム}.md` を優先して参照する。

### モバイル可読性
- 段落: 3〜5文（長い段落は分割する）
- 文: 40字以内を推奨、60字超過は禁止
- 対話と叙述の交互配置: 連続する叙述は5文以下

### スカッと／もやもやのバランス
- スカッと場面（読者が「ああ、スッキリした」と感じる場面）はエピソードあたり最低1回
- もやもや場面（じれったい状況）は2話以上の連続を禁止する
- もやもやの後のスカッとの落差が大きいほど読者の満足度は上がる

### 見せ場の場面
- 主人公が相手を圧倒する場面: 過程を見せる（結果だけ見せると盛り上がりに欠ける）
- 相手の表情／反応を通じて主人公のすごさを間接的に伝える
- 「見せる(showing)」原則: 読者が自分自身で「うわ、すごい」と感じるようにする

### 課金転換区間
- 課金転換の直前エピソード（プロットガイドに明示）はフック強度を最大に設定する
- 無料区間でも有料水準の品質を維持し、読者の信頼を構築する
- 課金転換の直後エピソードは即座に報酬（スカッと）を提供し、課金満足度を高める

## 6. カクヨムプリセット執筆原則（厳選大ヒット路線）

`target_platform: カクヨム` で厳選大ヒット路線を採る場合に追加適用する。正本は `${CLAUDE_PLUGIN_ROOT}/skills/design/references/platform-preset-kakuyomu.md`。

### 感情のジェットコースター
- 登場人物の感情を激しく上下させる。一話内でも「上げてから落とす／落としてから上げる」振幅を作る
- ただし感情は解説せず、行動・身体反応・台詞で見せる（2.5 節の原則を厳守する）

### 短期カタルシスと長期伏線の両立
- 各話に一般読者向けの短期カタルシス（即効の快感）を最低 1 つ残す
- 同時に、考察層向けの長期伏線を最低 1 つ仕込む。伏線は「設置→回収」対応表で管理し、回収は物語 80〜100% に集中させる
- 表層（短期カタルシス）だけ追っても楽しめ、深層（伏線）に気づくと評価が跳ねる二層構造を意識する

### 絶望と希望の灯
- 各章 50% と物語 50% には「全てを失う絶望」を遠慮なく書く。苦しみは物語をまたいで持続させてよい
- ただし各章末には「部分的勝利・希望の灯」を必ず残す（完全解決ではなく、次へ進む意志・小さな勝利・関係の前進のいずれか）
- 50〜80% の再起区間では、各話に前進または伏線回収を 1 つ以上置き、忍従だけの話を作らない
- 各章・物語全体のハッピーエンドは絶対遵守。完全な大団円は物語ラストにのみ置く
