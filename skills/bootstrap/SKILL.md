# Novel Bootstrap — ブートストラップ文書生成スキル

Web 小説の基礎設計文書を生成する。この文書はキャラクター設計者とプロット設計者が作業する土台となる。

## 作業手順

1. `references/genre-dna-framework.md` を読みジャンルフレームワークを把握する
2. ユーザーの小説コンセプト（職業、雰囲気、差別化方向）を分析する
3. 以下の出力テンプレートに沿ってブートストラップ文書を作成する
4. 既存人気作との類似度を点検し、差別化ポイントを明示する

## 出力テンプレート

```markdown
# [作品仮題] — ブートストラップ文書

## 1. 作品概要
- **ログライン**: 一行要約（主人公 + 中核葛藤 + 差別化ポイント）
- **ジャンルタグ**: [主要ジャンル]、[サブジャンル]、[追加タグ]
- **ターゲット投稿プラットフォーム**: [カクヨム/小説家になろう/アルファポリス/ノベルアップ+/エブリスタ/ノベルピア のいずれか 1 つ]（→ 拡張可能性）
- **想定分量**: [総話数] / [1 回あたり文字数]
- **トーン & ムード**: [雰囲気キーワード 3～5 個]

## 2. 世界観設定
- **時代背景**: [叙事開始時点] ～ [現在/未来]
- **専門分野**: [職業群 + 具体的な細分分野]
- **専門分野の深さ戦略**: [専門知識を叙事に溶け込ませる方法]
- **社会的脈絡**: [当該職業の社会的位置、権力構造]

## 3. 叙事起点設定
### 3-1. 主人公の過去/背景
- **最高点**: [主人公が到達したか到達できたであろう位置]
- **挫折/転換**: [叙事を駆動する中核事件 — 悲劇/契機/変化]
- **感情的核心**: [読者が感じる共感/怒り/期待の核心]

### 3-2. 叙事動力
- **トリガー**: [叙事を始動させる契機]
- **開始状態**: [主人公の叙事開始位置/状況]
- **中核能力/資産**: [主人公が持つ特別な力量や情報]

### 3-3. 中核力量モジュール
| 時点 | 情報/能力 | 活用方法 | 叙事的機能 |
|------|----------|----------|-----------|
| [時点] | [情報/能力] | [主人公が活用する方式] | [どんな叙事効果] |
| ... | ... | ... | ... |

## 4. セリングポイント
- **中核差別化**: [既存作品比で独特な点 1 つ]
- **主要快感要素**: [読者が感じるカタルシスの種類]
- **慣れ親しみ : 新しさ比率**: 7:3 基準でどこに新しさを配置したか

## 5. プラットフォーム戦略
- **モデル種別**: [課金モデル (ノベルピア) ／ 無料公開＋書籍化／PV 還元モデル (なろう、カクヨム、アルファポリス、ノベルアップ+、エブリスタ)]
- **無料公開区間**: 1～[N] 話（1 巻分量）
  - 課金モデルの場合: ここまで無料公開、N+1 話から有料化
  - 無料公開モデルの場合: 全話無料が前提。N は「書籍化スカウトの試し読み終端」または「読者離脱率の山」を示す
- **読者保持転換時点**: [N] 話（ランキング進入条件分析、書籍化スカウト判断分析、または有料化判断分析）
- **読者保持転換フック**: [転換時点に配置する叙事イベント]
- **日次連載計画**: [連載周期、備蓄分戦略]

## 6. メディアミックス拡張性
- **コミカライズ適合度**: [視覚的場面の比重]
- **ドラマ化適合度**: [現実背景の活用度]
- **中核ビジュアル化場面**: [コミカライズ/ドラマで映える場面 3 つ]

## 7. 既存作品比のポジショニング
| 比較作品 | 類似点 | 差別点 |
|----------|--------|--------|
| [作品 1] | [共通要素] | [この作品ならではの違い] |
| [作品 2] | [共通要素] | [この作品ならではの違い] |
```

## 中核チェックポイント

- [ ] ログラインが一文で作品の魅力を伝えているか
- [ ] 主人公の過去/背景が読者の共感/期待を誘発するか
- [ ] 中核力量モジュールが最低 10 項目以上か
- [ ] 差別化ポイントが明確で既存作品と区別されるか
- [ ] 専門知識の深さ戦略が「香りだけを漂わせ流れは断ち切らない」水準か
