# キャラクターの対話 DNA — 状況感応型の対話設計ガイド

キャラクターシートの非言語タグが**身体**のパレットだとすれば、この文書は**言葉**のパレットである。
各キャラクターが情報をどう処理し、どんな論理で話し、状況に応じてどう変奏するかを定義する。

episode-rewriter は台詞を書くときにこの文書を参照し、character-sculptor は台詞の DNA 整合性を診断するときに参照する。

---

## 1. 対話 DNA とは何か

非言語タグがキャラクターの身体的反応を定義するものだとすれば、対話 DNA はキャラクターが**なぜ、どのように**話すのかを定義する。

| 次元 | 非言語タグ (既存) | 対話 DNA (新規) |
|------|-------------------|----------------|
| 対象 | 身体 — 手、視線、姿勢 | 言葉 — 語彙、論理、リズム |
| 機能 | 感情を見せる | 思考の仕方を見せる |
| 反復のリスク | 「また同じ動作」 | 「また同じやり方で驚く」 |
| 変奏の方法 | 5 段階の強度 | 状況タイプ別の思考経路の変奏 |

**核心原則**: 同じキャラクターであっても、**良い知らせを聞いたときの反応**と**危機に直面したときの反応**は思考経路が異なる。非言語だけでなく、台詞の内容・構造・長さも変わらなければならない。

---

## 2. キャラクター別の対話 DNA プロフィール

キャラクター別の対話 DNA プロフィールは novel-config.md で指定された `character_dialogue_dna` ファイルから読み込む。
当該ファイルがない場合は、キャラクター詳細文書 (character_detail) のキャラクタープロフィールを参照する。

### 対話 DNA プロフィール作成テンプレート

新規プロジェクトが対話 DNA ファイルを作成する際は、以下のテンプレートを参考にする。

#### キャラクター DNA プロフィール様式

```yaml
思考パターン: [結論の導き方。例: 「結論 → 根拠 → 沈黙」 / 「経験 → 比較 → 感情」]
情報処理: [新しい情報を受け取ったときの処理の仕方。例: 「即座に検算」 / 「自分の経験に照らして理解」]
説得の方式: [このキャラクターが説得される方法。例: 「データで」 / 「感情的な同意が先」]
感情の漏出: [感情が表に出る瞬間。例: 「家族の話題が出たとき」]

台詞_DNA:
  構造: [長さ、文の特徴。例: 「短い(10～25字)。主語の省略が頻繁。」]
  語彙: [使用する言葉の特徴。例: 「抽象語禁止。具体的な数値のみ。」]
  特徴: [固有の台詞の癖。例: 「話の途中に計算を差し挟む。」]
  禁止: [絶対にしないこと。例: 「感嘆詞、自慢。」]
```

## 3. 状況タイプ別のキャラクター反応マトリクス

同じ出来事に複数のキャラクターが同時に反応する際、**全員同一反応の禁止**原則を適用するためのマトリクス。

プロジェクト別の character_dialogue_dna ファイルに、キャラクター別の反応マトリクスを定義する。

**作成原則**: 3 名以上が同時に反応する際は、マトリクスから**異なる列**の反応を選ぶ。
驚きだけ 3 名 --> 驚き + 検算 + 保留 などへ分化させる。

---

## 4. 対話の反復防止 — 変奏の技法

### 4-1. 同じキャラクターの台詞の単調さを防ぐ

同じキャラクターが一つのエピソードの中で同じ方式でしか反応しないと単調になる。

**規則: 一話の中で同じ思考経路は 2 回まで。** 3 回目は別の経路で反応させる。

### 4-2. 情報伝達の台詞のキャラクター化

純粋な情報伝達が必要な台詞も、キャラクターの DNA を通過させる。

**原則**: 情報を伝達しつつ、その情報が**このキャラクターの人生において何を意味するのか**を一行添える。

### 4-3. 話をまたいだ対話の変奏

直前の 2 話で同じキャラクターが同じ思考経路を使っていたら、今回の話では別の経路を選ぶ。

## 5. 叙述体の中の対話 — Web 小説の技法

### 5-1. 対話は場面の一部である

対話文は独立して存在しない。**空間・視線・行動の流れの中で**発話される。

```
悪い例 (台本式):
キャラクターA: 「数値は合ってるのか？」
キャラクターB: 「はい。」
キャラクターA: 「本当に？」

良い例 (叙述体):
キャラクターAが精算書を指でなぞった。数字の下を二度叩いた。
「数値が合っているだと？」
手帳を開いて見せた。
「初めての収穫です。」
キャラクターAの手が止まった。精算書の上に置かれたまま。
```

**核心**: 台詞の前後に**視線・手・空間**がある。台詞だけを並べれば台本である。

### 5-2. 台詞と台詞の間の叙述 — 呼吸をつくる

台詞と台詞の間に叙述を入れ、その叙述が**次の台詞の重みを準備する**ようにする。

### 5-3. 沈黙を叙述する方法 — 「沈黙した」の代わりに

「沈黙した」は最も怠惰な沈黙の描写である。沈黙には**質感**がなければならない。

| 「沈黙した」の代わりに | 伝わるニュアンス |
|---------------|--------------|
| 空気が重くなった。 | 緊張 |
| コーヒーが冷めるまで、誰も書類に手をつけなかった。 | 衝撃のあとの静寂 |
| 窓の外から物音だけが聞こえた。 | 寂寞 |
| ペンが手帳の上で止まったままだった。 | 決断の直前 |

### 5-4. 対話のリズム — 短い台詞と長い叙述の交差

```
[短い台詞]  「数値。」
[長い叙述]  書類の上で視線が数字を追った。一行、二行。
[短い台詞]  感嘆。
[短い叙述]  固有の動作。
[長い台詞]  個人的な文脈を含んだ反応。
```

## 6. 診断基準 (character-sculptor 参照用)

### DIALOGUE 診断チェックリスト

| 項目 | 基準 | 方法 |
|------|------|------|
| DNA 整合 | キャラクターの思考パターンが台詞に反映されているか？ | character_dialogue_dna ファイルの台詞 DNA と照合 |
| 状況感応 | 状況タイプに応じて台詞経路が変わっているか？ | 反応マトリクスと照合 |
| 話の中の変奏 | 同じ思考経路が 3 回以上反復されていないか？ | §4-1 |
| 話をまたいだ変奏 | 直前の 2 話と同じ思考経路が 3 話連続になっていないか？ | §4-3 |
| 情報のキャラクター化 | 情報伝達の台詞にも個人的な文脈が乗っているか？ | §4-2 |
| 叙述との統合 | 台詞が叙述の流れの中にあるか？ (台本式は禁止) | §5-1 |

### スコア基準

| スコア | 意味 |
|------|------|
| 9～10 | すべての台詞が交換不可能。このキャラクターだけの思考パターンが表れている。状況別の変奏が自然。 |
| 7～8 | ほぼ整合しているが、1～2 箇所に機能的な台詞 (情報のみを伝達) がある |
| 5～6 | DNA は合っているが変奏がない。同じ思考経路だけを反復している |
| 3～4 | 他のキャラクターと交換可能な台詞が多数。個性が希薄 |
| 1～2 | DNA とまったく異なる台詞。完全な書き直しが必要 |
