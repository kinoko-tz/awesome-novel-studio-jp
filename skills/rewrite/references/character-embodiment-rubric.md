# キャラクター立体性 採点基準表 (Character Embodiment Rubric)

quality-verifier と character-sculptor がキャラクターの立体性を点数化する際に使用する **0〜10点の採点基準表**である。

---

## 7つの次元別 採点基準

### 1. VOICE (対話の固有性) — 0〜10点

| 点数 | 基準 |
|------|------|
| 0-2 | 大部分の対話が他のキャラクターと交換可能。終止語尾・口調がキャラクターシートと不一致 |
| 3-4 | 終止語尾は一致するが、思考パターン・観点が一般的。交換可能な対話が50%以上 |
| 5-6 | キャラクター固有の口調が一貫しているが、情報伝達の対話でDNAが抜ける。交換可能な対話が20〜50% |
| 7-8 | 大部分の対話でキャラクターのDNAが感じられる。交換可能な対話が10%未満。状況別の変奏あり |
| 9-10 | すべての対話がこのキャラクターだけの思考パターンを反映。話者表示なしでも誰なのか分かる |

### 2. NONVERBAL (非言語描写) — 0〜10点

| 点数 | 基準 |
|------|------|
| 0-2 | 非言語がない、または「彼は笑った」程度のタグ直結のみ存在 |
| 3-4 | 非言語はあるが機械的な挿入(タグ直結3件以上)。因果順序が未遵守 |
| 5-6 | 因果順序(刺激→身体→行動→対話)を部分的に遵守。同じ非言語を3回以上反復 |
| 7-8 | 因果順序を一貫して遵守。キャラクター別の固有な非言語を使用。強度が事件に比例。反復2回以下 |
| 9-10 | 非言語が描写に完全に溶け込んでいる。5段階の強度変奏が自然。3エピソード間で反復なし |

### 3. INNER (内面の反映) — 0〜10点

| 点数 | 基準 |
|------|------|
| 0-2 | キャラクターの内面(欲望/恐怖/矛盾)がまったく現れない。機能的な存在 |
| 3-4 | 設定上の動機は言及されるが、行動と結びつかない |
| 5-6 | 動機が行動の一部に反映される。内面の葛藤が間接的に見える |
| 7-8 | 行動・選択・沈黙から内面が一貫して現れる。矛盾が自然な緊張として作用する |
| 9-10 | 各場面で内面が行動の動力となる。読者がキャラクターの次の行動を予測しながらも驚かされる |

### 4. RELATION (関係の力動) — 0〜10点

| 点数 | 基準 |
|------|------|
| 0-2 | キャラクター間の関係が平面的。すべての相手に同一に反応する |
| 3-4 | 関係の設定はあるが、対話・行動に反映されない |
| 5-6 | 主要な関係において距離感/親密感が部分的に反映される |
| 7-8 | 関係の段階に応じた呼称・トーン・距離感が一貫している。alive-tracker のアーク段階と整合する |
| 9-10 | 関係の微妙な変化が非言語・対話・行動に自然に染み込んでいる。読者が関係の変化を「感じる」 |

### 5. ASTONISHMENT (驚愕の固有性) — 0〜10点

| 点数 | 基準 |
|------|------|
| 0-2 | すべてのキャラクターが同一に驚く(「目を見開いた」「口があんぐり開いた」だけを使用) |
| 3-4 | キャラクター別の驚愕の仕方はあるが強度の変奏がない(常に同じ反応) |
| 5-6 | 驚愕の仕方は固有だが、イベントの重みと比例しない |
| 7-8 | キャラクター別の固有な驚愕の仕方 + 事件の重みに応じた5段階の強度変奏。同じ驚愕がエピソード当たり2回以下 |
| 9-10 | 驚愕がキャラクターのアイデンティティを表す道具として作用する。圧倒(5段階)時の対比効果が劇的 |

### 6. CATHARSIS (カタルシスへの寄与) — 0〜10点

| 点数 | 基準 |
|------|------|
| 0-2 | カタルシス場面への寄与なし。背景人物の水準 |
| 3-4 | カタルシス場面に存在するが、反応が形式的 |
| 5-6 | 主人公のカタルシスを部分的に増幅する役割 |
| 7-8 | カタルシス場面で固有な反応により読者の感情を増幅する。スカッとする場面の観衆の役割を果たす |
| 9-10 | このキャラクターの反応そのものがカタルシスの一部。読者がこのキャラクターの視点から共に感じる |

### 7. DIALOGUE DNA (対話の思考パターン) — 0〜10点

| 点数 | 基準 |
|------|------|
| 0-2 | 対話が情報伝達のみを担う。思考パターンがない |
| 3-4 | 口調はあるが、情報を処理する方式(分析型/直観型/感情型など)が一般的 |
| 5-6 | キャラクターのDNAが部分的に反映されるが、機能的な対話では抜ける。同じ思考経路を3回以上反復 |
| 7-8 | すべての状況類型(良い知らせ/危機/葛藤)で固有な思考経路をたどる。交換不可性90%以上 |
| 9-10 | 対話だけでキャラクターを識別できる。状況別の変奏が自然で、成長に伴う変化も反映される |

---

## 総合点数の算出

### 主人公/中核キャラクター (各EPに登場)
- 7つの次元すべてを評価
- **総合点数 = 7つの次元の平均**
- PASS基準: 平均7.0点以上、個別の次元5.0点以上

### 主要な脇役 (当該EPに5文以上登場)
- 評価次元: VOICE, NONVERBAL, RELATION, DIALOGUE DNA (4つ)
- **総合点数 = 4つの次元の平均**
- PASS基準: 平均6.0点以上

### 端役/背景 (当該EPに1〜4文登場)
- 評価次元: VOICE (1つ)
- **総合点数 = VOICE の点数**
- PASS基準: 5.0点以上

---

## REWRITE判定の連動

quality-verifier の REWRITE モードにおいて:
- **キャラクター立体性の平均7点以上** → PASS条件を充足
- **キャラクター立体性の平均5点未満** → 即座にREWRITE
- **5〜7点の間** → 他の軸と総合して判定(個別の次元が3点以下のものが2つ以上 → REWRITE)
