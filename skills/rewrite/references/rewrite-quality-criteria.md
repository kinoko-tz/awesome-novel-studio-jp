# 再執筆品質基準

エピソード再執筆の品質を判断する具体的な基準である。

---

## 1. キャラクター立体性基準

### 1-1. 核心原則: 叙述文の中のキャラクター

Web小説のキャラクターは**叙述の流れの中で**生きていなければならない。非言語タグを機械的に挿入するのではなく、その行動が**なぜ今この瞬間に出てくるのか**が叙述から自然に読み取れる必要がある。

**悪い例 — タグ挿入式:**
```
キャラクターAが固有の動作をした。「セリフ。」
```
これが10話ごとに繰り返されると、読者は「また同じ動作」と感じる。

**良い例 — 叙述に溶け込んだ非言語:**
```
キャラクターAの手が固有の動作で持ち上がった。だが、やり遂げなかった。しばらくためらってから口を開いた。
「個人的な文脈が込められたセリフ。」
```
同じ動作でも、手が持ち上がる過程・やり遂げないという選択・ためらう持続時間が**この場面の感情の重み**を伝える。

### 1-2. 状況感応型の非言語

キャラクター詳細文書(character_detail)の非言語タグは**パレットの基本色**である。同じ色でも濃度と質感が変わらなければならない。

**強度別の変奏原則:**

| 強度 | 定義 | 非言語処理 |
|------|------|------------|
| 1 (微弱) | 予想範囲内の情報 | 動作が始まりかけて止まる。または動作なしで視線だけ移動 |
| 2 (注目) | 興味深いが驚くほどではない | 固有の動作の縮小版 |
| 3 (驚き) | 期待を超える情報 | 固有の動作の完全な実行 |
| 4 (衝撃) | 世界観が揺らぐ | 固有の動作 + 後続行動 |
| 5 (圧倒) | 言葉を失う | 固有の動作すら出ない。代わりに**今までになかった行動**が登場 |

強度5で「固有の動作をしない」キャラクターは、普段との対比で衝撃の大きさを伝える。

### 1-3. 同一話内の反復防止

一つのエピソード内で**同じ非言語表現が2回を超えてはならない。**同じキャラクターの同一の非言語が3回以上出ると、読者に「作家のレパートリーが狭い」という印象を与える。

**規則:**
- 同じキャラクターの同一非言語: 1話あたり2回以下
- 同じキャラクターの同じ感嘆詞: 1話あたり1回
- 非言語のないセリフも混ぜる — すべてのセリフに非言語を付けるとかえって過剰になる

### 1-4. 直前2〜3話の反復防止 (話間の反復)

再執筆時には**直前2話で使用したキャラクター別の非言語を確認**し、同じ強度・同じ表現が3話連続で登場しないようにする。

方法: 直前のエピソードをgrepして当該キャラクターの非言語使用状況を把握したうえで、今回の話では**異なる強度または異なる変形**を選択する。

### 1-5. こだまの対話 vs 生きた対話

**こだまの対話 (悪い例)**
```
キャラクターA: 「数値です。」
キャラクターB: 「数値だって？ すごい。」
```

**生きた対話 (良い例)**
```
キャラクターAが手帳を開いて見せた。「数値です。」
キャラクターBが固有の動作をした。「個人的な文脈が込められた反応。」
```
違い: キャラクターBの反応に**個人的な文脈**が入ることで、そのキャラクターだけの経験が表れる。

### 1-6. 叙述文で書くキャラクターの反応

Web小説の叙述文において、キャラクターの反応は**カメラが捉える順序どおりに**見せなければならない。

**原則: 因果の順序**
1. 刺激 (数値発表、事件、セリフ)
2. 身体反応 (無意識的 — 手、視線、呼吸)
3. 意識的行動 (非言語タグ)
4. セリフまたは沈黙

**原則: 中間動作の発見**
キャラクターがAからCへ飛び越えないようにする。A→B→CにおいてB(中間動作)が、キャラクターの個性が表れる瞬間である。

### 1-7. キャラクターアークに伴う対話の変化

キャラクターの対話のトーンは固定ではない。関係が変われば対話も変わる。
キャラクター詳細文書(character_detail)の関係変化段階表を参照する。

### 1-8. 驚愕の交差汚染診断

キャラクター詳細文書(character_detail)の驚愕方式の交差汚染表を参照する。
各キャラクターが絶対にしない行動/感嘆詞の一覧は、プロジェクト別のキャラクター設定に定義されている。

## 2. 叙述文対話ガイド

### 2-1. 対話は行動の一部である

Web小説において、対話文は独立して存在しない。**叙述の流れの中で**行動・視線・空間とともに流れる。

### 2-2. 脇役のセリフに生涯がにじむように

脇役が情報を伝えるとき、その情報に**自分の経験・記憶・利害関係**を一行載せると、キャラクターになる。
各キャラクターがどのような生涯要素をにじませるべきかは、キャラクター核心文書(character_core)と対話 DNA 文書を参照する。

### 2-3. 全員同一反応の禁止

同じ事件に3人以上が同時に驚く場合、**最低1人は別の感情**で反応しなければならない。

---

## 2-5. 対話 DNA 品質基準

セリフのキャラクター整合性と自然さを判断する基準である。
詳細な DNA 定義は、対話 DNA 文書(novel-config.mdのcharacter_dialogue_dna)および `${CLAUDE_PLUGIN_ROOT}/skills/rewrite/references/character-dialogue-dna.md` を参照する。

### 2-5-1. セリフの交換不可能性 (核心基準)

セリフの話者を別のキャラクターに変えても**違和感がなければ** DNA が不足している。

**判定**: 交換可能なセリフが一人のキャラクターに2件以上あれば、DIALOGUE スコアを減点する。

### 2-5-2. 状況感応型の変奏

同じキャラクターであっても、**状況の類型に応じて思考経路が変わらなければならない。**

**規則: 同じ思考経路は1話あたり2回まで。3回目は別の経路にする。**

### 2-5-3. 情報伝達セリフのキャラクター化

純粋に情報のみを伝える「機能セリフ」は禁止。情報に個人的文脈を載せる。

### 2-5-4. 話間の対話思考経路の反復防止

直前2話で同じキャラクターが**同じ思考経路**を主に使用していたら、今回の話では別の経路を選択する。

## 3. プロットビート整合基準

novel-config.mdで指定されたプロットガイドのビートとエピソード本文の整合度を3段階で判断する:

| 等級 | 基準 |
|------|------|
| **整合** | ビートの核心事件・感情強度・フック類型がすべて一致 |
| **部分整合** | 核心事件はあるが、感情強度またはフック類型が異なる |
| **不一致** | 核心事件そのものが異なる |

不一致 = CRITICAL、部分整合 = MAJOR、整合 = OK

## 4. フック強度判断

| 強度 | 基準 |
|------|------|
| 5 | 読者が即座に次の話を購入する。反転・衝撃・絶体絶命 |
| 4 | 次の話が気になる。新キャラ・新たな危機・結果の保留 |
| 3 | 関心は維持される。伏線の提示・方向転換 |
| 2 | 平凡な締めくくり。次の話を必ず見るべき理由が弱い |
| 1 | フックなし。読者離脱の危険 |

再執筆目標: 最低3

## 5. 分量・形式基準

| 項目 | 基準 | 許容範囲 |
|------|------|----------|
| 分量 | 5,000字+ | 4,500〜8,000字 |
| 段落 | 2〜3行 | 最大4行 |
| 文 | 15〜25字 | 10〜35字 |
| 対話比率 | 40〜55% | 35〜60% |
| 場面転換 | 3〜4回 | 2〜5回 |
| 沈黙パターン | 1話あたり4回以下 | — |
| 同一非言語の反復 | 1話/キャラクターあたり2回以下 | — |
| 同一感嘆詞 | 1話/キャラクターあたり1回以下 | — |
| 同一思考経路の反復 | 1話/キャラクターあたり2回以下 | — |
| 機能セリフ(情報のみ) | 0件 | 情報に個人的文脈が必須 |
| 交換可能なセリフ | 1キャラクターあたり1件以下 | — |
| 台本式の対話羅列 | 0件 | セリフ間の叙述が必須 |
